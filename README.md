### 🏙️ [City Smart Pulse Dashboard — Roorkee](https://github.com/disha1526/city-smart-pulse)
> **Tech:** Python | ETL Pipeline | NLP (TextBlob) | Anomaly Detection (Isolation Forest) | Time Series Forecasting | Streamlit | Power BI | SQLite | Plotly

A real-time smart city analytics system built for Roorkee using live weather and air quality APIs, NLP on citizen complaints, and ML-based anomaly detection — all connected to an interactive Streamlit dashboard and Power BI report.

- ✅ Built end-to-end **ETL pipeline** — pulls live data from open APIs → cleans → stores in SQLite database
- ✅ Applied **NLP sentiment analysis** (TextBlob) on citizen complaints to classify Positive / Negative / Neutral feedback
- ✅ Implemented **Isolation Forest anomaly detection** to flag unusual weather patterns automatically
- ✅ Built **7-day temperature forecasting** using Exponential Smoothing (Statsmodels)
- ✅ Developed **multi-tab Streamlit dashboard** with KPI cards, live charts, and interactive filters
- ✅ Created **3-page Power BI dashboard** with DAX measures, slicers, and data model relationships
- ✅ Exported structured data to Excel for Power BI live connection
